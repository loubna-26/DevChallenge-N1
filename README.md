# Portfolio 

## Descripción

Proyecto web desarrollado como parte de mis prácticas de Desarrollo de Aplicaciones Multiplataforma (DAM).

El objetivo del proyecto es crear una página web utilizando tecnologías básicas de desarrollo web.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

## Estructura del proyecto

* index.html → estructura de la página web.
* index.css → estilos y diseño.
* index.js → funcionalidades JavaScript.
* Lht.png → imagen utilizada en el proyecto.
* GitHub.png, Gmail.jpg, Link.jpg → recursos gráficos del proyecto.

##  Cómo ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `index.html` en un navegador.
